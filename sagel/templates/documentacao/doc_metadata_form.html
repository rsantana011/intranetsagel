Controle de acesso

No acesso restrito, basta pertencer a um dos perfis, setores ou usuários selecionados. Administradores e gestores de Documentação têm acesso para gerenciar. Sem seleção, somente esses gestores acessam.

Use o mesmo nome do setor cadastrado no perfil das pessoas. Nos campos de seleção, segure Ctrl para escolher mais de uma opção.
